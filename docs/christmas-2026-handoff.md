# Christmas 2026 preview handoff

Based on origin/master e93665f. The existing working tree had separate uncommitted reservation and wine changes; this worktree does not include them. No AGENTS.md was found in the repository. The default branch is master and its push workflow deploys GitHub Pages. The latest master adds schedule sharing compared with the brief; the home and special-offer routes still shared the 2025 event, and the menu has 26 locales. The menu manages language independently of global i18n. Existing analytics include GTM and GA as well as tracking hooks; duplication needs an audit before changing measurement.

The legacy reserve screen sends requests for 2025 and contains its own completion screen. The separate reservation-success route also contains example bank information and is not linked by the new event. Existing reservation lookup and administration remain unchanged; their authorization and personal-data exposure need review before reuse. The new event never calls these APIs. Client-side disabling is not server authorization: no 2026 reservation endpoint exists here. Server-side event state, capacity and pricing validation, idempotency, concurrent booking, cancellation, identity verification and migration of old reservations remain required before opening bookings. Do not deploy database changes or test with real reservations.

The Naver URL is deliberately null pending confirmation, although an existing footer contains an unverified short link. The preview does not claim booking is available. Dates, start times, capacity, deposits, payment and cancellation terms, final prices and images remain unapproved. The course and pairing prices are shown as proposed values. The event is a draft preview, not an operational booking flow.

Production readiness still requires approved brand copy and imagery; server-side reservation design and security tests; validated Naver link and click analytics; accessible mobile and desktop QA; and static HTML, per-page metadata, sitemap, direct URL HTTP status and social sharing verification. Existing single-page fallback is not sufficient for search. The legacy completion page should be consolidated after its real consumers and historic data are checked. The new pages must not be merged to master until the preview content and remaining deployment work are approved.

Local review: install dependencies with `npm ci`, run `npm run dev`, and visit `/events/christmas-2026/` and `/en/events/christmas-2026/`. Rollback after a future deployment should revert the merge commit on a separate branch and deploy through the normal approved process; preserve reservation data and existing internal routes.
